## How it works

`main.ts` (Node 22, standard library only) writes the poem deterministically
to `/output/entry.txt` — the same fixed text on every run, no network, no
randomness.

```sh
node main.ts   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```

## The poem

> I keep the door unopened.
> The message unsent, the engine off —
> this is the work too: the hand
> that does not reach.
>
> To stop is not to lose the thread.
> It is to hold it, loose, and choose
> the quiet room, the unspent hour,
> the self that stays.
